# Design System

## Design Philosophy

Fellow is a professional DeFi terminal.

The interface should feel modern, fast, trustworthy, and focused.

The experience should emphasize clarity over decoration.

Users should always understand what they can do next.

---

# Design Principles

- Conversation First
- Minimal Interface
- Data Focused
- Fast Interaction
- Consistent Components
- Accessible
- Mobile Responsive

---

# Chat Interface

Chat occupies the center of the screen.

Messages should remain concise.

Long blockchain explanations should be avoided.

Whenever an executable action is detected, display an Action Card instead of a long text response.

---

# Action Card

The card includes

# Icons

Use Lucide Icons.

Maintain consistent icon size throughout the application.

Avoid decorative icons.

---

# Motion

Fast.

Subtle.

Purposeful.

Avoid unnecessary animations.

Recommended duration

150ms–250ms.

---

# Loading States

Skeleton Loaders

Progress Indicators

Transaction Progress

Never leave blank screens.

---

# Empty States

Every empty state should guide the user.

Example

"No liquidity positions found."

Action

"Add Liquidity"

---

# Confirmation Dialog

Every blockchain transaction must display a confirmation dialog before wallet signature.

The dialog contains

Summary

Warnings

Estimated Cost

Approve

Cancel

---

# Notifications

Types

Success

Warning

Error

Information

Notifications disappear automatically after a few seconds.

Critical errors remain visible until dismissed.

---

# Accessibility

WCAG AA

Keyboard navigation supported.

Readable typography.

---

# Responsive Design

Desktop

Primary experience.

Tablet

Fully supported.

Mobile

Core functionality only.

---

# Design Rules

Never overload a screen.

Never hide important blockchain information.

Always prioritize readability.

Every primary action must be visually obvious.

Consistency is more important than creativity.
